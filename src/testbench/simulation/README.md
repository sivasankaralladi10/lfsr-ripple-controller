# Simulation Results

## Tool

Cadence Xcelium / SimVision

## Verification

The LFSR-based ripple controller with decoder was functionally verified using a Verilog testbench.

The simulation observes:

- Clock
- Reset
- LFSR output
- Binary decoder output
- Ripple signal

## Testbench

The `tb_lfsr.v` testbench generates the clock, applies reset, runs the design for 200 ns, and monitors the outputs.
